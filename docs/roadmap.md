# Roadmap

- [x] **M0 – Skeleton**: repo, CI, Compose + Material You shell
- [x] **M1 – Engine**: FFmpegKit fork chosen ([ADR 0001](adr/0001-ffmpeg-library.md)), pure-Kotlin command builder + probe parser with JVM tests, `FfmpegKitEngine` (probe, run, cancel, progress) verified on an arm64 emulator, quick-compress dev screen for one picked file
- [x] **M2 – Batch & background**: Hilt, Room (`batch`, `batch_item`), `CompressionWorker` under a foreground notification (cancel current / cancel all), crash and stop recovery, no-gain rule, completion notification, share receiver (temporary: queues with the Share preset), queue screen with picker, pause/resume, remove. Verified on an emulator, including a real share intent. Still open from the original foundation list: DataStore, navigation shell, onboarding/permissions screen
- [x] **M3 – Presets & dialog**: shared compression sheet (share target + picker) and preset editor with live command preview, size estimate, codec/container validation, name-template preview; user presets in Room (migration 1→2, built-ins stay in code), default/last-used preset in DataStore, preset CRUD and JSON import/export through the share sheet, navigation shell (Queue, Presets, Preset editor). Verified on an emulator (sheet, save-as, export chooser)
- [x] **M4 – Completion actions**: `Finalizer` + `MediaStoreWriter` (save alongside, replace in place or by swapping container, reshare, discard), ffprobe verification before anything is overwritten, `FinalizeActivity` consent flow (`createWriteRequest` / `createDeleteRequest`, none with `MANAGE_MEDIA`), results notification actions, "Ready to use" list on the Queue screen, export modes applied automatically, 14-day cleanup of unclaimed results
- [x] **M5 – History & stats**: History screen (finished batches, a single-item batch shown as the item, per item sizes / reduction / preset / dates / outcome, exact ffmpeg command with copy), Stats tab (all time / year / month / week, grouped per preset, never merged), computed from the existing `batch` and `batch_item` tables so there is no schema change
- [x] **M6 – Auto compression**: gallery scan (MediaStore), age tiers with the oldest match winning, off-peak windows / whenever charging / external only, charger + battery gates with mid-file stop, hourly `AutoScanWorker`, dry run and run now, Auto screen, heavy-video suggestions on the Queue screen, launcher shortcuts ([docs/automation.md](automation.md)); the token-gated external API of this milestone was removed later. Verified on an emulator (scheduled run, `adb` commands, unplug and stop)
- [x] **M7 – Polish**: first-run permissions screen and a Permissions page (videos, location, notifications, `MANAGE_MEDIA`, battery), Settings (theme and wallpaper colours, default preset, unused-result retention, notification channels, staging storage with Clear), About (privacy, GPL-3, FFmpeg source offer, bundled third-party notices), signed release build and tag-triggered release workflow, fastlane metadata, [distribution notes](distribution.md). Verified with the R8-minified release APK on an emulator. Not built: trash holding / undo for replaced originals, concurrency setting, Quick Settings tile
